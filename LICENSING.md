**Why `LICENSE` is the plain Apache-2.0 text.** It used to be this pointer document, which is accurate
but unclassifiable: GitHub's licensee could not recognise it and reported the repository as
`NOASSERTION`, so an automated dependency scan saw a repo with *no* licence. That is a real adoption
blocker and it was raised by a prospective implementer (sirenic-eu/sirenic-examples#2, 2026-08-26).
`LICENSE` is now the verbatim Apache-2.0 text so scanners classify the repository correctly; the
specification's CC-BY-4.0 grant is unchanged and lives in LICENSE-CC-BY-4.0.

Implementing GVP requires no permission, no licence grant beyond the above, and no notification to
the authors. The specification is published so that anyone may implement it.
